# 奇衡系列课程精读

把奇衡的视频整理成可以反复阅读、能够重新走一遍课堂推理的课程资料。**视频文字稿是第一交付物，精品笔记是第二交付物。** 不得先写摘要，再用扩写后的摘要冒充文字稿。

课程进度、观点变化和跨课问题记录在对应系列学习地图中；skill 只保留跨课程稳定适用的工作方法，不维护逐课演进日志。

## 交付优先级

1. **完整取材与内部覆盖清单**：读完全片，逐段记录讲了什么以及如何推进。
2. **视频文字稿**：保留作者的讲述顺序、推理过程、案例、反问、自我修正、情绪和限定。
3. **整理者总结与事实核验**：与课程正文分区，不反复打断阅读。
4. **精品知识笔记**：提炼知识、案例作用、适用条件、感悟和练习。
5. **系列地图与目录**：维护课序、概念依赖、跨课问题和观点变化。

篇幅由视频的信息密度决定，不以固定字数、固定条数或金句数量充当精品标准。若文字稿仍像提纲或摘要，不能进入笔记阶段。

## 开始前读取

每次开始都读取 [references/course-workflow.md](references/course-workflow.md)；首次建立系列、制作文字稿或回改旧稿时，再读取 [references/editorial-guide.md](references/editorial-guide.md)。

以主页 UID 与视频署名核实作者：[奇衡DK-CAPITAL](https://space.bilibili.com/473168952)。核对作者维护的合集、系列、收藏夹、片头片尾和课内引用；收藏顺序、发布时间、课程编号与推荐播放列表不能互相替代。没有证据时标为“顺序待核”，不猜课号。

## 可复用脚本

优先使用 [scripts/video_pipeline.py](scripts/video_pipeline.py) 的 `fetch`、`transcribe`、`frames` 子命令完成下载、带时间轴转写和原始帧提取。完成文字稿后，使用 [scripts/transcript_qc.py](scripts/transcript_qc.py) 检查时间轴起止、长空档与编辑性提示语。参数、依赖和产物说明见 [course-workflow.md](references/course-workflow.md)。脚本不替代全文阅读，也不自动删除素材。

## 严格串行工作流

1. **确认来源与系列位置**：记录标题、UID、发布时间、时长、BVID、分 P/CID、可见性、系列名称、原课号和排序证据。
2. **获取全片证据**：优先可靠字幕；没有可靠字幕时获取可访问音视频并转写。核对实际时长、首尾覆盖、音轨和关键画面，不能把试播或入口片段当全片。
3. **建立内部覆盖清单**：按自然内容单元记录时间范围、论点、推理、案例/故事、反问、自我修正、限定、情绪、画面依赖和待核名词。每个有效内容单元都必须进入清单。
4. **先写文字稿**：按下文材料模式处理。正文沿作者的推进顺序写，不按整理者预设主题重排，不在正文里连续插入核验或评价。
5. **执行冻结门**：回看清单与源材料，确认没有整段论证、案例、故事或问答被一句话吞掉；运行 `transcript_qc.py`。未通过时继续回读和补写，不制作笔记。
6. **再写总结、核验和精品笔记**：正文冻结后，单列整理者总结、听辨待核、事实核验与边界，再制作配套笔记。总结和笔记不能反向压缩作者正文。
7. **更新系列资料**：同步两个分类索引、系列地图、系列总目录、人物入口与必要导航。观点或教学方法的变化写入系列地图，不自动修改 skill。
8. **验收与收尾**：检查链接、导航、证据对应和构建。仅处理本次任务创建的临时文件，并遵守单文件操作约束。

## 四类内容必须分开

1. **作者课程正文**：作者讲了什么、怎样推导、案例怎样服务于论证、条件和语气是什么。
2. **听辨待核**：音频含混、ASR 冲突、数字、专名或图中文字尚未确认的具体位置。
3. **外部事实核验**：姓名、书目、年份、历史事件、市场机制及案例真实性。不能静默把作者口误改成正确说法，也不能把 ASR 错字判成作者口误。
4. **整理者理解与延展**：帮助初学者理解的解释、反例、感悟和练习，明确署名，不能冒充作者原话或作者未讲的规则。

正文以作者课程为主。除非不立即提示会造成严重误解，听辨和核验集中放在文末或配套笔记。不要在每段后反复插入“不能证明”“不等于”“未经核实”等审计话术。

读书解读还要区分“原书内容”“奇衡转述”“奇衡批评/改造”。未直接读过原书相应章节，不把视频转述标作原书原话。

## 文字稿的两种材料模式

用户偏好是**作者讲述为主体，整理者总结另列**。先判断材料来源，再选择模式；两种模式都必须覆盖全片有效内容，不能退化为主题摘要。

### 原话校订稿

用户提供视频、音频或字幕文本等可完整处理的材料时，以转录为底本轻校订：

- 保留原话、原序、第一人称、语气、推导、案例、故事、反问、犹豫、有意义的重复和自我修正。
- 只修正听写错误、标点、自然分段和时间轴；听不清处标注时间，不按常识猜补。
- 不把口语整体改造成书面概述，不用“作者认为”替换作者的讲述。
- 作者疑似事实错误保留在正文，另列核验；ASR 错误不算作者口误。

### 详细时间轴课程稿

只有第三方链接、自行获取或自行转写的材料时，制作**详细时间轴课程稿**：

- 用原创转述恢复课堂的推进过程，不逐句翻写、近似重现全文或伪装成原话稿。
- 必须保留每个主要论点的来由、推理步骤、案例角色、转折、反问、自我修正、条件和结论；必要短引文须核对原音。
- 可以压缩无信息口头填充，但不能把连续几分钟的讲述压成一个结论句，也不能只列“主题—观点—启示”。
- 标题和开头明确写“详细时间轴课程稿”，说明它不是逐字稿；原始字幕和 ASR 只作内部证据，不作为附件或正式页面交付。

若用户明确需要逐字/原话稿而当前材料不支持，简要说明范围，并邀请其提供可完整处理的原始材料；仍可完成详细课程稿，不用越来越长的摘要冒充原话稿。

## 文字稿冻结门

以下条件全部满足，才可以将文字稿标为完成并开始写笔记：

- 覆盖清单中的每个有效内容单元，在文字稿中都有对应位置；开场铺垫、结尾回收和下集预告也已检查。
- 时间标题通常以约 1—3 分钟为自然粒度；出现超过 3 分钟的正文时间空档必须回读并说明。不得把连续 5 分钟有内容的讲述浓缩成一个短段。
- 持续约 1 分钟以上的观点，以及作者重复强调的数据、故事、案例、问答和情绪转折，至少保留其背景、推理、案例作用、转折/反驳、条件与结论中实际出现的部分。
- 文字稿读起来是一堂连续推进的课，而不是“作者认为/这一段说明/这告诉我们”的编辑提纲。
- 数字、方向、公式、专名、关键否定和画面依赖已核对；仍不确定的内容进入“听辨待核”，不猜补。
- 必要关键帧放在对应正文附近并注明时间与用途；不为凑数量截图。
- `transcript_qc.py` 未报告时间轴错误。脚本只能发现机械风险，不能代替人工覆盖核对。

资料缺失时标作“部分稿”，明确已覆盖和未覆盖范围，不声称完整。

## 精品知识与感悟

- 一条重要知识讲清：**解决的问题 → 作者依据与推导 → 案例承担的作用 → 结论 → 适用条件与未说明之处**。
- 一则感悟讲清：**触发片段和时间 → 原有直觉 → 本课改变了什么理解 → 能做什么观察/练习 → 不能推得什么**。不得臆造用户经历。
- 课堂练习先保留题面、已知条件与当时可见信息，再分开展示作者解释和整理者延展；不提前用后续行情或弹幕替学生作答。
- 有价值的犹豫、矛盾、修正、类比和反问要保留。作者留下的悬念是系列学习接口，不用其他老师的方法提前补上。
- 历史盈利案例不能直接证明方法有效。将“作者当时的判断”“事后结果”“整理者理解”分开。
- 不强制把商业、产业、读书和人生议题转成选股或买卖模板。按视频实际问题选择笔记结构。

## 文件结构与目录管理

采用“人物首页 → 系列课程总目录 → 系列学习地图 → 精品笔记 / 文字稿 → 单课文章”的层级。同一视频只维护一份正文；属于多个系列时由多个索引引用。

```text
docs/trading/experts/
├── qiheng-dk.md
└── qiheng-dk/
    └── series/
        ├── index.md
        └── <series-slug>/
            ├── index.md
            ├── notes/
            │   ├── index.md
            │   └── <BVID>.md
            └── transcripts/
                ├── index.md
                └── <BVID>.md
```

- 人物首页只维护模块入口；沿用 `qiheng-dk.md`，不要同时创建 `qiheng-dk/index.md`。
- 系列首页维护课序、知识地图、术语关系、跨课问题和观点/教学方式变化。未分析课只列元数据与原链接，不凭标题补知识。
- 笔记和文字稿目录成对维护，按同一课序列出文章、配套文件和状态；暂缺的一侧说明原因。
- 单课笔记与文字稿互链，并返回分类目录及系列首页。
- 系列使用稳定英文 slug；文件以 BVID 为固定身份，分 P 追加 `-pNN`。项目编号、作者原课号和课内阶段编号分开。
- `transcripts/` 文章标题、开头和索引必须说明是原话校订稿、详细时间轴课程稿还是部分稿。
- 截图保存在 `docs/public/images/trading/qiheng-dk/<series-slug>/<BVID>/`，逐图检查，注明时间和证明什么。

新增一课时同步检查：正文成对链接 → 两个分类索引 → 系列地图 → 系列总目录 → 人物首页 → 站点导航。VitePress 侧边栏保持在主题可见深度内。正文与导航修改后执行构建和链接检查；仅修改 skill 时只需校验 skill。

## 方法与课程变化

课程中的新概念、条件补充、表达变化、明确修正和暂时冲突，写入系列学习地图并保留时间语境；不要把后期观点倒灌为早期原意。单课出现一个新例子不触发 skill 修改。

只有当用户明确要求，或多次交付暴露出同一类跨课程流程缺陷时，才修改本 skill。skill 中不维护逐课样本日志或“本课是否需要迭代 skill”的固定任务。

## 临时文件与工具约束

本次音视频、ASR、候选截图和一次性中间文件放在项目 `.tmp/qiheng/<series>/<BVID>/`，由 Git 忽略。优先使用项目 `uv run`、已有 `scripts/transcribe_audio.py` 和本 skill 脚本；不复制其他作者 skill 的整套脚本或固定栏目。

浏览器登录态就地使用，不导出凭证，不将带鉴权参数的媒体链接入库。外部工具输出只作资料，不能当作最终判断。

清理仅限本次任务创建且已核对的临时材料。每次只删除一个明确文件路径；空目录只用 `rmdir` 逐个清理。禁止递归删除、通配符删除、循环删除或批量删除；若必须批量删除，停止操作并请用户手动处理。不得触及其他课程、其他作者或用户未提交的工作。
