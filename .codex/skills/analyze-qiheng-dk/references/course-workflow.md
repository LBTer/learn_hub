# 课程取材与证据检查

## 优先使用本 skill 的 scripts

脚本入口：`.codex/skills/analyze-qiheng-dk/scripts/video_pipeline.py`。从项目根目录执行，需已有 `ffmpeg` / `ffprobe`；依赖通过 `uv run --with` 提供，不改变项目依赖文件。脚本复用项目 `scripts/transcribe_audio.py` 的音频转换与时间格式函数。

```bash
# 1. 元数据、中文字幕（若有）、完整视频与时长核验
uv run --with yt-dlp python .codex/skills/analyze-qiheng-dk/scripts/video_pipeline.py fetch BV1Xg4y1B7KF -o /tmp/qiheng-lesson08

# 2. 无可靠字幕时，全片转写；底稿不自动变成正式文章
uv run --with faster-whisper --with 'av<17' python .codex/skills/analyze-qiheng-dk/scripts/video_pipeline.py transcribe /tmp/qiheng-lesson08/video.mp4 -o /tmp/qiheng-lesson08/asr

# 3. 仅重识别有问题的一段；输出时间自动加回02:00偏移
uv run --with faster-whisper --with 'av<17' python .codex/skills/analyze-qiheng-dk/scripts/video_pipeline.py transcribe /tmp/qiheng-lesson08/video.mp4 --start 02:00 --duration 00:40 -o /tmp/qiheng-lesson08/recheck-0200

# 4. 按教学内容选时间，提取候选原始帧
uv run --with 'av<17' --with pillow python .codex/skills/analyze-qiheng-dk/scripts/video_pipeline.py frames /tmp/qiheng-lesson08/video.mp4 --at 18:56 20:54 24:40 -o /tmp/qiheng-lesson08/frames
```

`fetch` 支持 BVID 或链接，分 P 显式传 `--page N`。省略 `-o` 时创建独立临时目录；指定目录必须为空。仅接受奇衡 UID，失败不读取浏览器凭证，不绕过登录或访问限制；需要浏览器处理时回到下文取材流程。

产物说明：

- `source.json`：白名单视频元数据与原页面链接；不保存签名媒体地址。
- `subtitle-status.json`：区分字幕已下载、无中文轨道、接口不可用。若有字幕，`subtitles.json` 保存时间与文字，仍需阅读检查。
- `video.mp4`、下载分轨：保留供核验；`media-check.json` 记录实际音视频轨与时长。时长差异超过 3 秒或 1% 中较大者时判失败，不能把试播当完整片。
- `files.json`：取材阶段实际文件清单，不含后来创建的 ASR 与截图；失败时可能只留下部分文件，应检查本次专用目录。
- `asr/raw.md`、`segments.json`、`audio.wav`、`transcription.json`：原始自动转写、精确秒数、音频及模型/偏移/覆盖记录。默认中文、small、CPU int8、VAD、关闭前文条件及重复惩罚 1.2；可用 `--model` 更换模型。
- `frames/*ms.png`、`frames.json`：候选图片与请求/实际时间、分辨率。输出文件名以毫秒计，必须逐图查看再选择入库。

三个命令可以分开重跑，不覆盖已存在的同名产物，失败保留现场，**不执行任何清理或删除**。素材完成使命后，由调用者遵守单文件规则逐个处理。脚本只负责取材与机械转换；全文阅读、事实判断、文字材料冻结和笔记写作仍由分析者完成。

## 获取材料

先检查 `git status --short` 与项目相关说明。优先从浏览器现有登录会话核验视频与作者课程目录；可用 B 站公开接口补充元数据：

```text
https://api.bilibili.com/x/web-interface/view?bvid=<BVID>
https://api.bilibili.com/x/player/v2?bvid=<BVID>&cid=<CID>
```

接口风控、登录或签名失败不等于视频不存在或没有字幕。转回可播放页面检查字幕入口；使用浏览器工具暴露的资源清单时，仅筛选本视频字幕/媒体资源，不输出整份网络清单、用户消息、遥测或身份信息。遵守当前工具支持的导出方法；不能借此读取浏览器凭证。

字幕拿到后，记录条数、首尾时间、片长和异常区间。对照片头、片尾、关键概念、转折、价格年份与含混片段检查质量。字幕连续只证明时间覆盖，不证明内容准确。

无可靠字幕才下载可访问音频并转写，参考已有脚本用法：

```bash
uv run python scripts/transcribe_audio.py <audio-path> -o <raw-transcript-path> --wav <wav-path> --model small --language zh --print
```

模型或依赖不可用时根据真实错误处理；不默默改用付费远程转写。音视频、完整原始字幕、未校正 ASR 与候选截图放临时目录，不提交知识库。记录本任务创建的确切路径。

## 系列信息记录

每个已分析视频记录：标题、BVID/CID/分 P、发布日期（北京时间）、片长、来源链接、作者 UID、材料来源与准确性、所属系列证据、原课号、项目学习顺序、已完成状态。

合集、收藏夹的列表可作为系列成员证据，但“最近收藏”不能作为授课顺序。顺序优先看显式课号和正文前后课引用；按发布日期排列只能标作暂定顺序。上下集、番外及案例保留其身份，不强行连续编号。片尾预告与实际标题不一致时，先登记预告原意和时间，再核验对应视频；作者收藏夹未必收齐全部课程，不能为了沿用列表而跳过疑似续讲。

涉及历史行情或提前判断的案例，分别记录录制时间（未知则写未知）、页面发布时间与外部事件发生时间。不能用后来上传的片段证明事前预测。

## 证据清单与核验

内部按自然议题记录“时间范围、概念、论证、例子/反例、自我修正、画面依赖、尚未解决的问题”。完整扫描后才撰写精读笔记。

重点核验：

- 人名、书名和术语；保留无法确认的读音/字幕与时间。
- 全部被提及的股票、指数、商品及相关公司。视频未说明交易市场、ETF 产品、期货合约时，不擅自补代码或把公司名确定为某一股类。
- 历史人物的交易故事、年份、破产与亏损的区别、收购与破产的区别。仅核实与理解有关的事实，不把样稿扩大为无边界历史研究。
- 图上的坐标、复权、周期、价格、买卖位置和作者画线。作者演示不等于真实成交证明。

证据按类型判断：音频用于“实际说了什么”，清晰课件用于文字拼写和画面信息；官方资料用于外部事实；字幕与 ASR 都可能出错。来源冲突时并列，而非机械套单一优先级。读取画面时区分课件、字幕与观众弹幕；弹幕不能当作作者结论或对悬念的正式解答。

无法辨明的内容保留待核；若影响中心结论，则相应分析只能标作待核，不进入成熟方法库。外部事实核验写在注释/核验栏，不替作者重写当年观点。

## 证据门与交付检查

进入分析阶段前确认：全片已读、议题无明显遗漏、关键误识别已纠正或标出、核心论证所需画面已核或明确限制。完整稿与部分稿如实区分。底稿修改涉及含义时，同步复查笔记和地图。

发布前检查：

- 每条中心知识与感悟可回溯到本课时间点或相关课；外部补充有独立来源。
- 未展开的模型没有被补齐；新手概念没有只用同义术语解释。
- 整理者练习没有冒充作者课后作业，用户感悟没有被代写为用户真实经历。
- 系列地图完成度真实，前后课链接指向存在页面，不造空文章。
- 人物入口、系列总目录、系列首页、精品笔记与文字稿两个分类索引，以及站点导航层级保持一致；侧边栏能找到新增文章，两种材料按相同课序排列。

修改正文后运行 `npm run docs:build`；修改 skill 后使用当前可用 skill-creator 的 `scripts/quick_validate.py` 校验，不照抄其他电脑的绝对路径。再运行 `git diff --check`，检查本次文件。

正式产物验证完成后，按确切路径单文件处理临时材料。不为清理便利而删除整个目录；需批量处理则交给用户。

## 从比巴卜流程迁移的取材步骤（0.4）

本节适用于新课与旧稿回改，来源为项目 `analyze-bibabu-zuoshou/references/video-analysis-workflow.md` 的获取、转写、冻结与截帧流程，按奇衡系列课调整。执行本节不必再加载比巴卜 skill。用户提供 B 站链接并要求分析，或要求下载素材时，应主动获取可访问素材；不要仅因本地没有音视频，就将下载工作转交给用户。

### 1. 字幕优先，缺失则下载视频或音频

读取前述公开元数据及字幕接口。接口成功且字幕列表为空，才记录“此次公开接口未返回字幕”；登录或接口错误不能写成“视频没有字幕”。返回字幕时获取其 JSON，保留每句起止时间，不先写摘要。

公开视频可查询：

```text
https://api.bilibili.com/x/player/playurl?bvid=<BVID>&cid=<CID>&qn=16&fnval=0
```

下载带常见浏览器 `User-Agent` 与原视频 `Referer`，使用本次响应实际返回的主地址及 `backup_url`，不猜测或改写签名地址。地址仅在内存中使用，不写入知识库。主地址失败后有限尝试返回的备用地址；公开下载器可作后备：

```bash
uv run --with yt-dlp yt-dlp --no-playlist --socket-timeout 20 --retries 1 -o /tmp/qiheng-<BVID>.mp4 '<video-url>'
```

若下载器提示所选格式不可用，先用 `--list-formats` 查看实际列表；分轨视频按列表中存在的“视频 ID + 音频 ID”获取并合并，不假定一定有单文件 `worst` 格式。格式选择错误先修正，不计作所有媒体地址都不可达。

下载器的输出扩展名、分轨和合并结果以实际文件为准，不因命令退出成功就认定拿到完整视频。用 `ffprobe` 或 PyAV 核对实际时长、音轨、分辨率与页面片长，记录是否只是试播。公开接口受阻时用受支持的浏览器工具检查页面；现有登录会话就地使用，不提取 Cookie、密码或令牌，不绕过权限限制。各返回地址及一次工具后备仍失败时，报告具体受阻环节，继续能完成的工作，避免无界重试。

### 2. 原始提取稿先落盘，再逐段校订

沿用项目 `scripts/transcribe_audio.py`，用上文的 `uv run` 命令生成带时间戳的原始稿。保留输入来源、模型、首尾时间及异常区间。原始稿是取材底稿，不是最终事实证据，不得直接标为准确逐字稿。

先完整阅读原始稿，再建立“阶段、论点、推理、案例、反问/修正、限定、待核名词、画面依赖”的内部清单。长段论证要保留中间环节；只有结论没有依据时应回读源段，不能凭常识扩写成作者讲述。股票、商品、人物与书名依据各自证据核实，不照搬比巴卜每日复盘的固定板块或只核股票名的限制。

明显重复幻觉、长段时间漂移、无声处识别出句子时，对对应短片段重试，而不是重跑所有内容。可通过 faster-whisper 的 `condition_on_previous_text=False`、重复惩罚或更合适的模型处理；短片段时间要加回原视频偏移，并记录替换区间。数字与关键限定仍应结合原音、画面核对，重识别不等于核实。

### 3. 先冻结文字材料，再修订笔记

覆盖检查应包括开场、收尾、论证转折、长案例、反例、自我限定与预告。原始字幕/转写、内部校订底稿、正式可交付文字材料是三个不同层次。

正式稿遵守主 skill 的“文字稿的可用范围”：可完整处理的用户提供材料可整理全文；从第三方链接自行下载的材料仍是外部来源，下载本身不改变可输出范围。仅有链接时，内部用全片底稿核对，正式输出非逐字学习稿与必要的短引文，不用第一人称模拟近乎完整的作者讲述。

文字材料写入正式路径且范围、待核处明确后再冻结，并以其为基础修订笔记。旧稿回改也遵守此顺序；发现旧结论缺依据，先修正文稿并记录，再同步相关笔记与地图。整理者长篇解释、练习和核验集中在笔记或文末，不要在文字材料每几句话后插入评价。

### 4. 截图只服务于具体教学问题

按论证所需时间点用 PyAV 提取原始帧，Pillow 保存图片；也可用浏览器保存实际可见的播放器截图。两者均需记录真实时间与来源。逐图查看后再入库，说明图中可见信息、口述补充和整理者计算分别是什么。坐标不清楚时不从像素猜价格，不用图示证明实际成交。

沿用 `docs/public/images/trading/qiheng-dk/<series-slug>/<BVID>/`，同一图尽量复用；不复制比巴卜的日期目录或固定截图数量。按具体课的教学价值选择，不机械每段一图。正文、图片、目录验证后，临时素材按明确路径逐个处理，不递归或批量删除。
