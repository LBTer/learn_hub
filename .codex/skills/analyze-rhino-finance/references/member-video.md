# RhinoFinance 会员视频学习工作流

## 目标与保存位置

会员视频用于系统学习 Rhino 的市场判断、公司研究、估值、买卖点、仓位纪律和投资理念。单期内容可追溯，多期观点可比较，预测可在后续检验。

按用户要求，整理后的会员文字稿、专题笔记和方法论记录纳入公开文档站及 Git，与其他人物专题一致，当前不实施网站登录校验。原始会员音视频、原始字幕与认证材料不发布；保留原视频链接和来源时间点。

每期创建：

1. `docs/trading/experts/rhino-finance/member-transcripts/YYYY-MM-DD-videoID.md`：完整、可读的时间轴文字稿。
2. `docs/trading/experts/rhino-finance/member-notes/YYYY-MM-DD-videoID.md`：会员专题学习笔记。
3. 更新人物主页、两个会员目录索引及 VitePress 导航；若本期出现值得跨期检验的新方法、公司研究变化或明确预测，再更新同一人物目录下的 `analysis-framework/`、`company-notes/` 或 `analysis-framework/prediction-ledger.md`。没有新证据就不强行追加。

自动任务只处理观察窗口内未处理的视频；历史课程按用户指定主题、期号或视频链接逐步补课。会员视频随后转公开时仍按视频 ID 去重，保留原始分析出处，并根据实际公开状态决定是否另写公开视频文档。

## 类型与访问核验

- 先核对频道 ID、视频 ID、标题、发布日期、时长、可见性、直播状态、字幕和章节。`subscriber_only`、`premium_only`、页面“会员专享”或明确会员栏目均是会员证据；标题“会员第 N 期”可辅助识别，不能单独替代实际可见性。
- 用用户已登录的 Chrome/YouTube 权限访问。账号可见标题但无法播放、下载或取得字幕时，标记“发现但未处理”并报告权限/技术原因；不得用预览、标题或他人转载编造内容。
- 尊重会员层级。不得尝试绕过付费墙、复制 Cookie、保存认证材料或向第三方转写服务上传会员音视频。

## 严格顺序

1. **原始提取稿**：获取官方/创作者字幕；不足时下载临时音频并在本机转写。原始稿保存于临时路径，按视频顺序保留语气、自我修正、案例、问答和条件句。
2. **整理文字稿**：逐段整理原始稿，标注自然时间点；结合画面核对表格、估值、支撑压力、图例和全部 ticker。读取 `ticker-verification.md`，建立全部标的提及表。只修正明显识别错误，不把外部分析写成 Rhino 原话。
3. **冻结文字稿**：检查开场至收尾、全部教学步骤、长篇推理链、反方观点、案例、数字、仓位/交易条件、风险、问答和自我修正均已覆盖；完整写入正式文字稿后冻结。缺失部分标“待补录”，不推断补齐。
4. **会员笔记**：只以冻结文字稿为内容底稿，提炼核心论证、可执行条件、适用边界和待验证项。外部来源只用于事实核验与反证，不替 Rhino 补造理由。
5. **跨期沉淀**：对照已有方法卡、公司跟踪和预测台账，记录延续、修订或矛盾。明确“首次提出”“本期再确认”“观点改变”和“尚未验证”，不把一次说法写成稳定体系。
6. **发布检查**：核对两份产物的日期、视频 ID、ticker、数字、时间尺度和来源；更新人物主页、会员索引和侧边栏，运行必要构建校验并提交本次正式产物。若使用 `docs/public/images/` 下的图片，先对本次目录执行 `npm run images:upload -- <本次图片目录> --rewrite`，成功后再校验和提交；网络错误用 `--concurrency=1` 重试，不用 `--all`。随后逐个清理本次临时文件。

文字稿发生实质修订时，同步检查会员笔记、方法卡和预测台账。任何阶段都不提前预写下阶段正文。

## 文字稿与会员笔记

文字稿保留 Rhino 原有的表达顺序、强调、例子、反问和条件。连续讲解约一分钟以上或反复论证的投资方法，不缩成一句结论；写出问题如何提出、每一步理由、图表或数据、相反解释、适用场景、失效条件与结论。每个自然议题标记起始时间，长段落增加时间点。对讲不清、画面难辨的数字注明“待核”，不要猜。

投资新手建议也要保留：从何处开始研究、如何区分估值和价格、仓位上限、现金/杠杆/期权风险、追涨或抄底条件、复盘方法和心态。记录提出建议的具体情境；不能把针对某位会员的回答扩张成通用规则。

会员笔记按实际节目结构组织，不强行套盘后复盘模板。建议包含：

```markdown
## 本期定位与学习目标
## 核心结论及其证据
## 研究或交易方法（步骤、输入、判断阈值、适用场景、失效条件）
## 公司、行业、ETF 与估值案例
## 会员问答（问题原意、回答、个案前提）
## 本期方法卡候选
## 预测与后续验证
## 事实核验和待补录
```

具体公司研究优先记录需求、竞争、盈利、现金流、资本开支、估值假设、价格区间与催化；交易方法记录信号、时间尺度、入场/加仓/减仓/避险条件、仓位与失效点。若视频是纯投资理念或课程，就以概念、推理链、示例和练习为主，不硬造 ticker 或买卖计划。

## 跨期学习记录

- **方法卡**：在 `analysis-framework/` 按方法或主题维护，逐次记录来源视频与时间点、Rhino 的原始规则、输入数据、决策步骤、适用市场和周期、仓位约束、失效情形、案例及后续修订。初次出现标“单期候选”；跨期一致且经过验证后再标“稳定框架”。
- **预测台账**：每条记录发表日期、视频 ID/时间点、标的/指标、方向或区间、时间尺度、触发条件、否证条件、当时数据来源、复盘日期和结果状态。未给期限或可检验条件的观点标“定性观察”，不计算命中率。
- **公司跟踪**：相同 ticker 跨期出现时比较估值假设、目标区间、支撑压力、仓位理由和反证。新一期与旧期冲突时并列记录当时理由，不用后见之明改写旧判断。
- 区分可验证事实、Rhino 主张和整理者分析；若模型或指标数据不是公开可复算的，标“视频引用”。不把事后走势简单归功于单期判断。

## 校验与边界

- 对重要财报、宏观数据、公司公告和产品名称优先使用一手来源；事实冲突时说明冲突，不改变主播当时的原话和判断强度。
- 不发布原始音视频、原始字幕与认证材料；临时文件只用于处理与核对，任务结束逐个删除明确路径。整理后的文字产物按上述目录正常提交和发布。
- 会员笔记是学习记录，不是实时交易信号。价格、估值和策略均标注视频日期与适用时间尺度。
