# 比巴卜作手

这里整理 B 站 UP 主“比巴卜作手”的交易思路、每日复盘、充电会员复盘、体系课程和技术点学习。

> 页面内容是对视频的学习整理，不构成投资建议。视频中的判断具有时效性，应结合后续走势验证。

## 当前认知

比巴卜作手的核心框架不是单纯找强势股，而是先判断市场环境，再把题材、资金风格、板块角色和个股反馈放到同一张图里。每日复盘通常从指数、量能和情绪开始，再进入题材强弱、核心票承接、后排反馈、仓位和次日预案。

目前文档中已经沉淀出的稳定认知：

- **周期优先**：先区分混沌、主升、退潮。混沌期偏小仓试错，主升期围绕主线核心和分歧买点，退潮期以空仓、防守或极小仓博弈为主。
- **题材是载体**：涨停数量不等于持续性。更关键的是核心能否主动、后排是否健康、中军或容量票能否承接、分歧后是否强回流。
- **核心票分层**：作者会区分龙头、情绪票、身位票、中军、容量票、弹性票、趋势核心、跟风、补涨和后排杂毛。真正的交易机会通常来自市场对这些角色的再选择。
- **周期口径决定龙头定义**：同一板块可同时存在短周期带动核心和跨周期穿越龙头。先明确观察窗口，再选择与持有周期一致的锚，不能用长周期地位替代当下带动性。
- **风格匹配模式**：机构趋势、量化轮动、情绪连板、消息套利、高低切和避险抱团，对应不同买点、持有周期和仓位。不能把所有上涨都套进同一种追涨逻辑。
- **分歧重于高潮**：一致高潮、消息首日过度一致、尾盘抢筹透支次日需求时，后手赔率通常下降；分歧后的核心承接和主动回流更有观察价值。
- **技术工具辅助确认**：均线、缺口、支撑压力、箱体、趋势线、量价、CCI、三日止盈和五日线纪律都常出现，但它们要和题材、情绪、资金风格、监管空间一起使用。
- **预案必须可证伪**：作者经常给出触发条件、失效条件和仓位动作。公告、外围、期货、竞价和盘中反馈都可以推翻前一晚预案；竞争失败、核心补跌或模式连续失效时，应及时退出或降仓。
- **突破后仍要筛买点**：指数突破与赚钱效应共振可以把战略仓位切回进攻，但高潮次日仍要防后排假弱转强；环境允许做多，不代表普涨里的每个高开都值得参与。
- **载体切换要看双向证据**：指数与情绪未退潮时，高位方向涨不动可以通过板块外高低切迁移到低位新题材；要同时看到旧载体高位票不表态和新载体持续扩散，才能把防守轮动升级为进攻切换。
- **冰点修复首先服务退出**：隔夜外盘和竞价反馈推翻修复预案后，水下冲高只按减仓窗口处理。卖出可以沿冲高、转弱、破位分笔执行，但不能把等待修复临时改成加仓赌反转。
- **非理性阶段先等待**：当量能不足、前排与后排割裂、弱回流缺少辨识度涨停时，常用战法和强弱判断的有效性都会下降。此时用极小仓试错只为感受市场，并明确区分“信息成本”和“进攻失败”；无法说明交易目的时直接休息。
- **择时、角色、赔率三重过滤**：战法和技术形态都排在周期择时之后。轮动期看到核心表态，不用“看 A 做 B”追映射后排；即使弱转强形态成立，也要用收益上限与潜在回撤检查盈亏比。权重护盘只说明指数暂时跌不下去，不自动等于短线拐点。
- **预案式“变脸”与强度排序**：成熟跟随不是坚持单一预测，而是预先写好涨跌两套动作；条件出现后及时切换。多板块同涨时按“谁先主动、谁带指数、谁在分歧中抗跌”排序，而不是只比较收盘涨幅。长期休息后的首次确认先恢复中等仓位，延续确认后再增加风险暴露。
- **强势混沌仍需寻找载体**：轮动方向冲高后能横住、负反馈缩小，只代表混沌变强，不等于主升。只有题材核心、容量与指数连续共振，才允许把环境升级为主升并提高仓位。
- **核心锚先于“分歧切核心”**：模式成立的前提是题材核心先给足客观强度。主观看好可以保留，但核心跌破均线、炸板无承接时，必须取消分歧买入；“预期是主观的，决策是客观的”。
- **板块周期与市场周期分开**：全市场可以处于修复日，旧板块仍可独立退潮；反过来也一样。先判断市场小周期，再判断单一题材的启动、分歧、修复或退潮，避免用指数涨跌替板块作结论。
- **强势轮动看回撤，风格切换等确认**：混沌期题材轮动不等于弱势，轮动后的回撤与炸板率决定体感强弱；老龙集体异动只能提示投机风格可能切回，仍要由次日梯队、持续赚钱效应和容错率确认，不能把收官动作直接当成新周期。

后续更新人物认知时，优先把新视频放回这些框架里验证：它是在补充周期判断、题材节奏、角色定位、具体战法，还是在修正某个失效条件。
