## 全片时间轴

### 00:00 分歧与一致为什么决定买卖点

作者开场把分歧与一致称为超短交易中非常重要的一组概念：如果不能理解二者，买卖点和操作就像“飘在空中”，很难找到适合自己的位置。

分歧是有人看好、有人不看好，持股者想卖、持币者想买，双方互为对手盘，因此成交量会放出来。一致是市场形成共同方向；当大家一致看多或一致看空时，对手盘不足，成交量反而出不来。作者用一句话概括：**爆量是分歧，缩量是一致**，但后文反复提醒必须再看位置与趋势方向。

![分歧与一致定义框架](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/0075.jpg)

**视频时间点：01:15**

### 01:10 分时上的一致：一字板与缩量加速

分时里最极致的一致看多是一字涨停。作者用神奇制药举例：哈药股份、百花医药等高位辨识度票见顶后，超短资金共同形成高低切和补涨预期，选择神奇制药作为补涨载体，资金共识最终表现为一字板；当天若想参与，往往只能提前隔夜排单。

没那么极致的一致是前一日爆量后，次日缩量秒板或缩量直线涨停。反方向同理，金螳螂前一日爆量后，次日缩量一字跌停，体现资金一致看空。作者由此再次强调：一致不等于上涨，一致只说明资金方向高度相同；缩量上涨是一致看多，缩量下跌是一致看空。

![分时图上的一致与分歧形态](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/0190.jpg)

### 03:53 分时上的分歧：宽幅震荡、烂板与尾盘炸板

作者列出三种常见分时分歧：宽幅震荡、放量封不住的烂板、尾盘炸板。宽幅震荡说明多空不断交换；烂板即使最终封住，板上持续放量和漏单也说明有人卖、有人接；尾盘炸板则把原本的一致封单重新打开。

他用双鹭药业的板上漏单说明：涨停封住后不断有大卖单涌出，分时量柱明显放大，单笔甚至出现约 1.95 亿元，这段就是分歧。上板或重新封住的过程，则是分歧重新转向一致。

### 05:31 日 K 上的一致与分歧

日 K 上的一致仍以缩量为核心：缩量加速、缩量连板、缩量涨停或跌停，都是方向共识。分歧常表现为底部放量大阳线、高位放量滞涨、长上影、长下影或十字星。

底部放量大阳线表示原来的一致看空被多头打破，是“空转多”的分歧转一致起点；但这只是资金方向开始变化，不代表立刻反转。高位放量滞涨、尤其放量长上影，则说明原来的一致看多受到强空头阻力，持有者要先考虑处理一部分。下跌后的放量长下影反过来可作为空转多信号，但仍需回踩或次日确认。

### 08:00 指数上的上下影线与组合 K

作者把放量长下影更多用于指数空转多判断：指数爆量收十字星或长下影，说明空头宣泄时已有资金承接；若后续回踩不破，可继续确认底部。两根 K 线有时也要组合看，单根缩量下影与前一根急跌合并后，可能对应一根更明显的长下影结构。

反过来，上涨阶段出现放量长上影，表示上攻遇到强抛压，需要考虑降低持仓。十字星、上影线和下影线的底层逻辑相同，都是多空在当前位置出现分歧。

### 09:22 爆量为什么常出现在底部建仓与顶部出货

作者把爆量解释为多空激烈交战，因此最常出现在两个位置：底部有多头开始建仓，或顶部有资金开始出货。

他用北陆药业讲底部过程：前期持续缩量下跌，说明市场仍一致看空；第一次相对放量阳线出现，说明已有多头抵抗，但相对前高成交量仍小，只能说明空头一致被打破，不能直接确认反转。随后若反复出现“放量上涨、缩量回落”，且底部支撑有效，更像主力在震荡吸筹。作者反对把“极致缩量后有反弹”偷换成“极致缩量后必反转”：从 ICU 到 KTV 需要吸筹过程，没有吸筹的个股或题材，大概率仍只是短促反弹或“三天小题材”。

![北陆药业底部量价与吸筹案例](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/0600.jpg)

**视频时间点：10:00**

连续缩量下跌后突然放量，只能确认有多头进场，后续仍要等分歧转强。若次日多头全部被砸回去，说明该次放量无效，盘面最多从单边空头转为震荡，还没有形成多头趋势。

### 13:23 顶部爆量与神奇制药的消息例外

顶部则相反。作者用神奇制药说明：高位由一致看多转为爆量分歧，往往对应资金出货；若没有后续消息刺激，正常预期应是次日深水甚至跌停。

但神奇制药当时还受到海外医药消息影响：默沙东的涨跌又刺激了个股一字涨停或跌停。因此，一字涨跌和爆量不能脱离消息环境机械套用。同样的形态如果叠加了强外部变量，次日路径可能被消息改变。

### 14:34 指数量价：缩量上涨未必坏，爆量阴线才要警惕

作者回看一段指数反转后的缩量上涨，认为只要趋势向上，缩量表示空头力量有限，并非天然不健康。真正需要小心的是连续缩量上涨后突然爆量，尤其出现爆量大阴线、阴包阳；如果爆量后回踩又缩量、随后继续上行，分歧仍可能再次转回一致。

因此量能不能脱离方向：上涨中的缩量可继续持有，下跌中的缩量不要抄底；连续上涨后的爆量阴线偏顶部风险，连续下跌后的放量抵抗才可能提供底部观察点。

### 15:51 四句简记与左右侧确认

作者给出四句简记：底部爆量看涨、顶部爆量逃命、上涨缩量持有、下跌缩量不抄底。但“底部爆量看涨”并不等于立刻买满，含义只是空头趋势可能转为震荡，多头开始入场；后面可能还有较长吸筹过程。

![量价位置四句简记](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/0970.jpg)

**视频时间点：16:10**

德明利案例用来区分左侧和右侧。连续下跌途中出现一次放量阳线，左侧资金可以把它视为多头入场并试错；更稳健的右侧做法，是等待次日继续上涨确认该次爆量有效。若次日马上把进场多头全部闷杀，之后继续缩量下跌，就说明转强没有成立。作者明确反对只因股价从高位腰斩、主观觉得“跌够了”就抄底。

### 19:11 战法的底层问题：到底买一致还是买分歧

作者说，实盘还要叠加周期、情绪状态和个股地位：当前是多头还是空头周期，是主升、混沌还是退潮；标的是龙头核心还是低位杂毛。各种弱转强、缩量反转、底部反转战法，最终都可追问同一个问题：它让你买在一致还是分歧？

他对连续缩量下跌时机械抄底的态度非常强烈，认为长期看胜率极低。更合理的路径是先等一致空头被放量打破，再根据次日或盘中反馈确认分歧能否转为一致多头。

### 20:10 分歧转一致的买点：百花医药第一次加速

作者把最理想的超短买点放在“分歧转一致”节点：高潮后进入分歧，分歧释放后重新回流，若能在这一转换点买到，就能覆盖后续上涨段。

百花医药的案例中，前一日成交量达到近期高位，分歧充分；次日缩量秒板，属于分歧转一致的确认。由于它又是医药板块高辨识度票，这个第一次缩量加速板可以参与。作者强调“第一次”二字：第一天加速可以考虑，第二、第三天连续缩量加速通常风险大于收益，除非市场处于主升期且标的确为板块龙头。

![百花医药分歧转一致确认](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/1285.jpg)

**视频时间点：21:25**

桂发祥被用作连续加速的反例：爆量启动后第一次缩量加速尚可参与，但继续缩量加速后，次日连溢价都没有。作者据此把底线定为只考虑第一次加速，不接第二、第三次连续一致。

### 23:35 弱转强必须服从情绪择时

作者再次强调弱转强只能在主升期重点使用；混沌期和退潮期不要机械做弱转强。原因不是图形定义改变，而是量化套利普及后模式超额收益下降，需要良好市场情绪帮助提高胜率。只有跌停板很少、情绪明显较好时，再考虑该模式。

![弱转强需要情绪环境加持](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17-part-2/1440.jpg)

**视频时间点：24:00**

### 24:44 两类补充买点：超跌板块与板块级弱转强

作者给出两类分歧转一致场景。第一类是猪肉等超跌板块连续缩量下跌后放量反弹，若后续放量上涨、缩量回落且底部支撑有效，可按波段观察。

第二类是板块前一日除龙头外大面积走弱，次日爆量龙头高开秒板并带动后排批量跟涨。这种板块级弱转强可在确认时半路或打板。不过他随即补充，理论买点也可能遇到分歧延续，不能把结构当成必胜公式。

### 26:11 一致转分歧的卖点

一致转分歧最直观的卖点，是连续缩量涨停后出现炸板爆量。百花医药第一次爆量时，按连板角度已是理论卖点；因为当日医药板块仍在加强，可以提高一点持股耐心，但再往后出现更强空头、长时间水下震荡，就属于更明确的卖点。板块视角可能允许核心多拿一段，连板视角则要更早处理，作者要求先说明自己使用的观察级别。

神奇制药同样从一致看多转为爆量分歧，最终炸板还叠加了大盘和全市场退潮。作者据此总结：板块龙头爆量阴线、跟风集体走弱，说明多头一致正在转向空头分歧甚至一致空头。

### 27:47 量化市场的节奏：买分歧，卖一致

作者把全课归结为：分歧是博弈，一致是共识；超短通常在分歧转一致时买，在一致转分歧时卖。主升期也可以直接买分歧，等板块回流；但不能买连续一致。

农业案例里，他口播罗牛山、金健米业说明量化节奏已经压缩：早盘板块一致杀向跌停，日内又从分歧转一致，一天走完过去几天的路径；如果参与者稍有留恋，隔日也可能没有利润。作者据此建议当前环境多吸分歧、少追缩量一致。

### 29:48 收尾：量能必须放回位置和趋势中

分时看日内博弈，日 K 看节奏；爆量要看位置，低位爆量可能是多头入场，高位爆量可能是出货；缩量要看趋势，上涨中缩量可偏正面，下跌中缩量则说明空头共识未破。所有缩量、爆量都不能孤立使用。

作者以指数举例：若指数始终站在五日线上，缩量阳线本身没有问题；真正不健康的是每次缩量只收小阳、每次爆量却收大阴。最后他再次强调，连续一致更容易转分歧，连续分歧更容易转一致，应用上尽量“买在分歧，卖在一致”。

## 本课术语表

| 术语 | 作者语境中的含义 |
| --- | --- |
| 分歧 | 多空观点不同、买卖双方激烈交换，成交量通常放大。 |
| 一致 | 市场共识看多或看空、对手盘不足，成交量通常缩小；一致不等于上涨。 |
| 分歧转一致 | 多空充分交换后，资金重新形成共同方向；超短买点通常寻找这一转换节点。 |
| 一致转分歧 | 连续缩量共识后重新爆量，原有方向受到对手盘挑战；高位常对应卖点。 |
| 第一次加速 | 充分放量分歧后首次缩量转强，是作者允许参与的一致买点。 |
| 连续一致 | 连续两天以上缩量加速；除主升期龙头外，作者认为风险通常大于收益。 |
| 左侧试错 | 底部首次爆量时把多头抵抗视为试错信号，但接受后续仍可能继续吸筹或失败。 |
| 右侧确认 | 等首次爆量后的次日或盘中继续转强，确认进场多头没有被反杀。 |
