## 一、本课定位与学习目标

- 系统位置：把量价、情绪周期和题材复盘落到“个股与板块当前是分歧、一致、回流还是走弱”的盘中判断。
- 前置知识：需要理解量价、K 线位置、核心票、后排、中军、题材复盘表、混沌期、主升期、退潮期和竞价反馈。
- 本课解决：如何用爆量 / 缩量识别分歧与一致，如何用核心、后排和中军划分板块强弱，如何选择分歧转一致买点与一致转分歧卖点。
- 学完能够：先看位置与趋势解释量能，再用板块角色确认节奏，在第一次加速或回流初期寻找机会，避开连续一致和无确认抄底。
- 本课不解决：每个题材的产业逻辑真假、个股基本面估值，以及所有案例的事后走势统计。

这节课的重点不是背术语，而是把“分歧”“一致”“回流”变成可观察的量价和板块结构。作者反复强调，量能必须放回位置、趋势和周期中解释；买点通常在分歧或回流刚确认时，不在连续一致之后。

## 二、核心规则与知识结构

### 核心规则

1. 爆量代表多空分歧，缩量代表方向一致；一致既可能看多也可能看空，量能必须结合高低位置和趋势方向解释。
2. 板块分歧与回流的强弱，要同时看核心、后排和中军：三类角色共振向下才是强分歧，共振向上才是强回流。
3. 超短优先做“分歧转一致”的第一次确认：充分爆量后首次缩量加速可以观察，第二、第三次连续加速通常风险大于收益。
4. 底部首次爆量只说明多头开始抵抗，左侧可以试错，右侧要等次日或盘中继续转强；连续缩量下跌不因“跌得多”而自动产生买点。
5. 交易环境优先于图形：弱转强主要在主升期使用；混沌期可做连续分歧后的核心修复，退潮期则回避机械弱转强和连续一致。

### 知识结构

![分歧回流定义框架](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/0005.jpg)

**视频时间点：00:05**

```text
板块状态判断
→ 看核心票：深水 / 跌停 / 红盘震荡 / 反包阴线
→ 看后排：区域跌停 / 分化 / 冲高回落 / 跟风涨停
→ 看中军：负反馈 / 震荡 / 反包 / 表态

强分歧
→ 核心深水或跌停 + 后排区域跌停 + 中军负反馈

弱分歧 / 分化
→ 核心红盘震荡或不给机会 + 后排掉队

强回流
→ 核心反包前阴线 + 后排跟随 + 中军表态

弱回流
→ 核心冲高 + 后排冲高回落

交易节奏
→ 爆发 / 高潮后不追一致
→ 分歧中买核心或等右侧回流
→ 连续分歧尾盘可博弈核心修复
```

补充视频把这套板块框架向下连接到单票量价：

```text
先定位置和趋势
→ 低位 / 高位，上涨 / 下跌
→ 再读量能：爆量是分歧，缩量是一致
→ 再等方向：分歧转一致，或一致转分歧
→ 最后叠加周期与地位：主升 / 混沌 / 退潮，核心 / 后排 / 杂毛
```

## 三、决策流程与使用边界

### 先用位置和趋势解释量能

![量价位置四句简记](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/2026-08-23/0970.jpg)

**补充视频时间点：16:10**

- 观察信号：成交量是相对放大还是缩小，发生在低位、高位、上涨途中还是下跌途中。
- 判断条件：低位爆量表示多头开始抵抗，高位爆量偏向出货风险；上涨缩量说明空头有限，下跌缩量说明一致看空仍未被打破。
- 对应动作：底部爆量只进入观察或左侧试错，右侧等待后续继续转强；连续上涨后的爆量阴线优先降风险。
- 常见误用：把“爆量看涨”“缩量健康”当成不分位置的万能结论。
- 失效边界：消息刺激、市场退潮和个股地位会改变同一量价形态的后续，不能只看一根 K 线。

### 只考虑分歧后的第一次加速

![百花医药分歧转一致确认](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/2026-08-23/1285.jpg)

**补充视频时间点：21:25**

- 观察信号：前一日充分爆量，次日缩量秒板或高开后快速封板。
- 判断条件：这是分歧转一致的第一次确认，并且标的具有板块辨识度。
- 对应动作：第一次加速可以按模式观察；第二、第三次连续缩量加速不再追接。
- 常见误用：只看到“缩量强”便连续排板，忽略先手供给已经累积。
- 失效边界：只有主升期的板块龙头，才可能承受连续一致；普通环境下风险收益不合适。

### 弱转强先问市场是否在主升

![弱转强需要情绪环境加持](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/2026-08-23/1440.jpg)

**补充视频时间点：24:00**

- 观察信号：跌停数量、整体赚钱效应、板块是否处于分歧后的修复窗口。
- 判断条件：弱转强图形只有在主升期、情绪明显良好时才获得环境加持。
- 对应动作：主升期优先做核心的第一次弱转强；混沌和退潮期主动降低参与。
- 常见误用：把弱转强当作脱离周期的固定公式，在任何环境都打板。
- 失效边界：量化套利压低模式溢价后，即使图形标准，择时与个股地位不够也可能失败。

### 先定义当天板块状态

![机器人强回流案例](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/0500.jpg)

**视频时间点：08:20**

- 观察信号：核心票是否深水、跌停、红盘震荡或反包；后排是区域负反馈还是跟随；中军是否表态。
- 判断条件：三类角色共振向下是强分歧，共振向上是强回流；只有局部票冲高，则多半只是弱修复。
- 对应动作：强分歧后看核心能否抗住或次日修复；强回流后把题材列为重点观察；弱修复一般偏卖点。
- 常见误用：只看一只个股涨停，就把整个板块定义为强回流。
- 失效边界：如果核心和中军没有配合，后排大面积冲高回落，不能因为个别票强就提高板块级别。

### 普通小题材：按“三天小题材”处理

- 观察信号：第一天消息爆发，第二天只有绝对核心顶住，后排水下开或冲高回落。
- 判断条件：题材逻辑不硬、后续催化少、后排不跟随，通常难以升级。
- 对应动作：若手上不是绝对核心，第二天走弱先卖；第三天防大分歧。
- 常见误用：看到核心一字，就误以为题材已经成主线。
- 失效边界：若分歧后出现强回流，核心、后排、中军重新共振，则需要重新评估题材级别。

### 主线题材：分歧后强回流必须重视

![强回流与中军表态](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/1110.jpg)

**视频时间点：18:30**

- 观察信号：预期分歧后，板块早盘给机会，随后核心反包、中军反包、后排跟随。
- 判断条件：持筹者本来以为要亏或只能平走，结果还能赚钱离场，这就是超预期。
- 对应动作：把题材列为潜在主线，分歧中买核心，或右侧确认回流后跟随。
- 常见误用：主线分歧时过早把所有后排都当卖点，忽略卡位和新前排。
- 失效边界：若只是盘中回流，收盘又转弱，不能按收盘强回流处理。

### 连续分歧尾盘买核心：只做逻辑题材和核心

![连续分歧尾盘买核心](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/3030.jpg)

**视频时间点：50:30**

- 观察信号：有逻辑的题材连续分歧两天，板块核心尾盘仍有承接。
- 判断条件：混沌期里，非退潮环境下板块连续三天无修复的概率较低。
- 对应动作：尾盘低吸板块核心，博弈次日弱修复或强修复；冲红即可按套利思路处理。
- 常见误用：买杂毛，或在退潮期还幻想连续分歧必有回流。
- 失效边界：板块进入退潮、核心破位、题材逻辑消失时，不用这个手法。

### 尾盘抢筹和离别钩：先手利好，接力利空

![尾盘抢筹的供需解释](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/3300.jpg)

**视频时间点：55:00**

- 观察信号：尾盘大量资金提前买入，股价被抢上去；或连板票无量急拉形成离别钩。
- 判断条件：尾盘抢筹会提前消耗次日修复需求，同时增加次日卖出供给。
- 对应动作：已有先手可把抢筹视为当日浮盈；次日接力资金要降低预期。
- 常见误用：把所有尾盘抢筹都当第二天强更强信号。
- 失效边界：逻辑特别强、板块合力很强时，尾盘抢筹后仍可能强更强；但离别钩更偏风险信号。

### 买在分歧和回流开始，不买一致

![左侧分歧和右侧回流买点](https://learn.luovista.com/trading/bibabu/member-hot-money-system/17/4520.jpg)

**视频时间点：75:20**

- 观察信号：板块竞价分歧、核心给低位机会，或盘中核心上板、后排同步上冲确认回流。
- 判断条件：左侧买点是分歧中博弈回流，右侧买点是回流开始后确认跟随。
- 对应动作：分歧时买核心，回流初期买辨识度；一致高潮次日以兑现为主。
- 常见误用：看到板块已经高潮、前排一字、后排高溢价后才追。
- 失效边界：强更强后再强更强，属于一致更加一致，风险收益不合适。

## 四、典型案例与对照

| 算力：华胜天成、鸿博股份、电光科技 | 区分后排掉队和真正强分歧 | 对照案例 | 核心没给极端负反馈时，不轻易定义为强分歧。 |
| 机器人强回流 | 展示分歧后强回流为何要重视 | 主案例 | 首个分歧后接强回流的题材，具备潜在主线意义。 |
| 军工：成飞集成、中航成飞 | 展示超预期回流和中军锚定 | 主案例 | 中军反包前阴线、核心带动回流，是强回流确认。 |
| 磁悬浮、纺织 | 展示三天小题材 | 反例 | 小题材第二天后排走弱，第三天防大分歧。 |
| 华为链 / 青岛金王 | 展示连续分歧尾盘买核心 | 手法案例 | 连续分歧后尾盘拿核心，博弈次日修复冲红。 |
| 尾盘抢筹 / 离别钩 | 展示先手和接力的供需差异 | 风险案例 | 抢筹对先手是利好，对次日接力可能是利空。 |
| 北陆药业 / 德明利 | 区分多头抵抗、吸筹和右侧确认 | 对照案例 | 底部首次爆量不是立即反转，后续量价反馈决定信号是否有效。 |
| 百花医药 / 桂发祥 | 对比第一次加速和连续加速 | 主案例 / 反例 | 分歧后的首次缩量确认可观察，连续一致不再追接。 |

### 主案例：军工分歧后的强回流

- 案例背景：军工周末预期是大分歧，早盘也确实几乎所有票给了机会。
- 作者拆解：成飞集成主动带动回流，中航成飞作为中军反包前一天阴线，后排也跟随，说明不是普通轮动。
- 对应规则：强回流要看核心、中军、后排共振；中军可以锚定板块节奏。
- 关键结论：预期分歧后还能反包，是超预期；但高潮后次日不适合再追一致，二次介入要等分歧。

### 反例：磁悬浮和纺织的三天小题材

- 对照关系：它们都有消息刺激和首日爆发，但后续逻辑、后排强度和持续催化不足。
- 容易误判之处：第二天绝对核心顶一字，会让人以为板块仍强；但后排水下开或冲高回落，已经暴露弱度。
- 作者结论：小题材手里不是绝对核心，第二天就要先处理；第三天防大分歧和补跌。

### 手法案例：连续分歧尾盘买核心

- 案例背景：混沌期里有逻辑的老题材连续分歧，第三天通常有修复预期。
- 作者拆解：尾盘拿板块核心，次日弱修复冲红即可套利；华为链、青岛金王是示例。
- 对应规则：只买核心，不买杂毛；退潮期不用。
- 关键结论：这不是看多题材长期，而是利用板块节奏做修复预期。

### 主案例：百花医药第一次分歧转一致

- 案例背景：百花医药前一日成交量达到近期高位，分歧充分，次日缩量秒板。
- 作者拆解：爆量代表多空充分交换，次日缩量加速表示资金重新形成看多共识；标的本身又有医药板块辨识度。
- 对应规则：只考虑分歧后的第一次加速，不接连续一致。
- 关键结论：买点不是“缩量”本身，而是充分分歧后的第一次缩量确认；桂发祥连续加速后无溢价形成反例。

### 对照案例：北陆药业与德明利的底部爆量

- 对照关系：北陆药业在连续缩量下跌后出现放量上涨、缩量回落的反复吸筹；德明利一次放量阳线后，次日进场多头很快被反杀。
- 容易误判之处：看到底部放量便把多头抵抗直接认定为趋势反转，或只因股价腰斩便主观抄底。
- 作者结论：底部首次爆量只把单边空头转为观察或震荡状态；左侧可小仓试错，右侧需要后续继续转强确认。

## 五、课后应用卡

### 实盘检查清单

1. 今天板块是爆发、高潮、分化、强分歧、弱回流还是强回流？
2. 核心票是深水、跌停、红盘震荡，还是反包前阴线？
3. 后排是区域跌停、冲高回落，还是有一两个跟风涨停？
4. 中军是负反馈，还是反包、放量表态？
5. 这是普通小题材，还是分歧后能强回流的潜在主线？
6. 当前买点是在分歧、回流开始，还是已经一致高潮？
7. 若连续分歧尾盘买核心，次日是套利思路还是格局思路？
8. 尾盘是否已抢筹，次日需求是否被提前消耗？
9. 当前爆量或缩量发生在低位、高位、上涨途中还是下跌途中？
10. 这是充分分歧后的第一次加速，还是已经第二、第三次连续一致？
11. 若是底部首次爆量，后续多头得到确认，还是次日已经被反杀？

### 本课与前后课程的接口

- 前置输入：第 2 课量价、第 3 课 K 线与位置、第 4 课复盘表、第 5 课看盘界面、第 6—7 课情绪与题材周期、第 11—12 课择时与竞价反馈。
- 向后输出：给弱转强、补涨、卡位、主线二波、尾盘套利和回流确认类战法提供个股量价与板块节奏的共同判断框架。

### 本课尚未解决的问题

- 中分歧、中修复如何量化。
- 主线题材中“后排也可能是买点”的卡位筛选标准。
- 尾盘抢筹在不同情绪周期下，对次日溢价的实际影响。
- 离别钩的稳定识别条件和更多案例对照。
- “爆量”“缩量”相对历史哪一段成交量比较，仍缺少统一阈值。
- 第一次加速在不同情绪周期中的有效率，以及左侧 / 右侧确认的仓位差异。
