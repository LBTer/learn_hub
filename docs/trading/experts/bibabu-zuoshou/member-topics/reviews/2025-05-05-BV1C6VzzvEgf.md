## 一、本课定位与学习目标

- 系统位置：这是一节连接“周期识别、候选池建立、节点确认和风险套利”的择时课。它不直接教一套固定买点，而是教交易者在旧龙头见顶、指数共振或突发事件出现时，怎样缩小观察范围。
- 前置知识：需要先能区分真正突破市场限制的龙头与普通最高板，也要理解首板、一进二、板块联动、情绪冰点和高低切。
- 本课解决：启动节点从哪里找、见顶日和断板日不一致怎么办、怎样用批量晋级率确认资金选择，以及龙头连续极端负反馈后有哪些不同风险层级的参与方式。
- 学完能够：先按日期建立候选池，再用次日整批反馈做验证；区分直接反核与抗跌票套利；识别高位双头更可能提供流动性，而不是确认第二波。
- 本课不解决：节点不能提前指定唯一龙头，也不能替代题材、筹码、板块推动和盘中主动性的判断；节后个股预案只是课程应用，不是确定性买卖指令。

## 二、核心规则与知识结构

### 核心规则

1. **先确认锚是不是龙头**：不是任意最高板都能定义节点。它至少要突破近期市场限制、打开高度或对情绪产生明显引导，才值得用其见顶和断板寻找低位切换。
2. **节点是一段窗口，不是机械的一天**：见顶日与断板日重合时，优先看当天首板；两者不重合时，把见顶日、断板日及其前一日的一进二一起纳入。行情越强，资金越可能提前一天抢跑。
3. **候选池必须由整批反馈确认**：节点的价值是缩小范围，不是事后指定答案。次日要比较同批首板、一进二的晋级率、板块推动和断板后的批量反包，判断资金最终选择哪一层。
4. **双冰反核只做高辨识度与深水赔率**：连续两个跌停附近只是经验上的流动性窗口，不代表“跌多必反弹”。对象要有龙头辨识度，价格要足够低，还必须看到大资金真实撬板。
5. **普通人优先研究抗跌票套利**：当龙头极端负反馈接近释放流动性，与其直接撬跌停，不如寻找同板块中拒绝跟跌、主动承接的票，交易板块修复时的相对强弱。

### 知识结构

```text
触发节点
├─ 龙头见顶 / 断板：寻找低位高低切
├─ 指数放量共振：寻找承担赚钱效应的板块
└─ 重大突发事件：寻找同批启动与持续晋级
        ↓
建立首板、一进二候选池
        ↓
用批量晋级率、板块推动和断板承接确认
        ↓
选择参与方式
├─ 启动节点：跟随真正被资金选中的批次
├─ 双冰反核：高风险、深水、只做高辨识度
└─ 抗跌套利：等待核心风险释放后的修复
```

## 三、决策流程与使用边界

### 场景一：龙头见顶或断板后的启动节点

- 观察信号：龙头已经突破过市场限制，随后出现见顶、断板或明显负反馈；低位票在同一时间窗口与其分离。
- 判断条件：先确定见顶日与断板日是否重合，再建立当天首板、前一日启动的一进二候选池；第二天比较各批次整体晋级率，而不是只盯住一只票。
- 对应动作：优先研究被资金整批选择、同时有板块推动和良好筹码形态的候选。节点票即使断板，也要继续观察是否出现批量反包或平台二波。
- 常见误用：把所有最高板都当龙头；只认断板当天；看到某只后来的牛股便反推当天所有首板都是有效节点。
- 失效边界：大主升中所有分支同时活跃，节点会被板块普涨模糊；候选只有孤立个股走强、同批晋级率低，也不能证明新周期已经成立。

![信隆健康断板日的中毅达节点案例，05:00](https://learn.luovista.com/trading/bibabu/2025-05-05-BV1C6VzzvEgf/0300.jpg)

### 场景二：指数共振与突发事件节点

- 观察信号：指数放量站上五日线，或印花税、疫情、贸易战等事件改变市场定价。
- 判断条件：必须看到板块与指数同步表态，或事件发生后出现一批共同启动、连续晋级的标的；单只消息票涨停不够。
- 对应动作：把承担短线赚钱效应的板块放到普通高标断板节点之前，再从同批核心、弹性和容量中做选择。
- 常见误用：把指数上涨和某个板块上涨的时间巧合当成共振；只根据消息影响力判断持续性，不观察资金兑现。
- 失效边界：指数没有放量、板块不承担赚钱效应，或突发事件只产生一日脉冲，节点优先级都要下降。

![贸易战突发节点的同批启动与晋级，29:35](https://learn.luovista.com/trading/bibabu/2025-05-05-BV1C6VzzvEgf/1775.jpg)

### 场景三：双冰反核

- 观察信号：真正龙头或高辨识度核心连续出现两个跌停附近的极端负反馈，封单开始被持续吃掉。
- 判断条件：买点必须在深水、接近地板，作者把约负八附近视作重要赔率边界；还要看到几千万、上亿元级别的真实撬板，而不是全天没有买盘。
- 对应动作：只按高风险隔日套利处理。第二次反核失败后，第三天等待释放流动性或冲高退出；不能临时把套利改成长线格局。
- 常见误用：机械在第二个跌停买、反核杂毛、价格抢到负一或红盘后仍追、不同仓位连续试错导致盈亏比失真。
- 失效边界：对象没有辨识度、深水位置无人承接、龙头继续封死，或退出通道和单笔亏损无法控制时，不应参与。

![杭钢股份双冰附近的反核案例，38:40](https://learn.luovista.com/trading/bibabu/2025-05-05-BV1C6VzzvEgf/2320.jpg)

### 场景四：抗跌票修复与高位双头回避

- 观察信号：龙头连续跌停时，同题材某只票没有被带崩；或者一波涨幅很大的老龙头高位反包，快速形成第二个头。
- 判断条件：抗跌票必须体现相对主动承接，并且龙头次日存在开板、板块弱修复或中修复预期。高位双头则要结合巨大累计涨幅、筹码交换不足和板块推动减弱判断。
- 对应动作：抗跌票在核心风险释放后按修复套利兑现；高位双头更偏向卖点和最后流动性，不把第二次冲高直接定义为新主升。
- 常见误用：把抗跌票的隔日修复改成趋势持有；把所有平台和二波都叫双头；忽略重新换手并带动板块形成新周期的例外。
- 失效边界：龙头继续封死、板块没有修复、抗跌票只是被动跟随，则套利逻辑失效；老龙头若充分换手并重新获得板块推动，则需重新评估双头判断。

## 四、典型案例与对照

| 案例 | 教学作用 | 类型 | 关键结论 |
| --- | --- | --- | --- |
| 信隆健康—中毅达 | 展示见顶日与断板日重合时如何找低位分离 | 主案例 | 先锁定断板日首板，再由后续晋级和反包确认 |
| 杭钢股份—新炬网络等 | 展示见顶与断板不一致时的两日窗口 | 主案例 | 见顶日和断板日都纳入，行情好时还要看前一日启动 |
| 1 月 14 日机器人、“924”金融 | 比较大盘共振节点与普通高低切 | 对照案例 | 指数、量能和板块同步表态时，共振节点优先级更高 |
| 4 月贸易战同批票 | 展示重大事件如何形成批量启动与晋级 | 主案例 | 事件越能改变定价，越要看同批覆盖面和持续晋级 |
| 双成药业、杭钢股份、威派格 | 展示双冰反核成功后仍按套利退出 | 正例 | 深水买入和真实撬板决定赔率，成功也不能擅自改模式 |
| 中毅达、航天科技、新炬网络 | 展示不开板、第三板才开和价格被抢高 | 反例 | 到了“第二个跌停”不等于必须买，赔率不合适就放弃 |
| 杭钢股份—拓维信息 | 展示更适合普通人的抗跌票套利 | 主案例 | 不直接撬龙头，交易核心风险释放后的板块修复 |
| 圣龙股份、艾艾精工、克来机电 | 展示高位双头的负反馈 | 风险案例 | 大涨后的第二次冲高通常更偏兑现点 |

### 主案例：信隆健康断板如何把候选缩到中毅达

信隆健康九板见顶，见顶日和断板日重合，节点日期相对清楚。中毅达当天在低位首板，并与高位负反馈形成分离，随后通过连板、断板反包走出较大行情。这个案例教的不是“断板日一定买中毅达”，而是先把研究范围缩到当天低位首板，再让后续批量反馈和个股主动性做淘汰。

### 对照案例：杭钢股份为什么需要两日窗口

杭钢股份第一波见顶与正式断板并非同一天，因此新炬网络、冀东装备、四川金顶、威派格、南兴股份和广聚能源等不同批次都要观察。部分候选走连板，部分走反包或平台二波，说明节点提供的是高容错候选池，而不是要求所有节点票始终连板。

### 反核对照：成功概率之外，更重要的是损益结构

双成药业、杭钢股份和威派格说明，第二个跌停附近若有真实资金撬板，次日可能提供冲高退出；中毅达和航天科技说明，有时第二个跌停仍不开、要到第三天才释放流动性；新炬网络则说明反核价格被抢得太高后，即使对象正确也应放弃。作者把它定义为盈亏比交易：允许多次小错，但前提是仓位一致、亏损受控，偶尔的大幅反核能够覆盖前面的试错。

## 五、课后应用卡

### 实盘检查清单

- [ ] 当前锚定的是突破过市场限制的真龙头，还是普通最高板？
- [ ] 见顶日与断板日是否重合？是否需要把前一日一进二纳入窗口？
- [ ] 候选批次次日的晋级率、板块推动和断板承接是否同步增强？
- [ ] 个股是主动与旧龙头分离，还是只被后排或消息反推？
- [ ] 若做反核，对象是否有足够辨识度、买点是否足够深、是否出现真实撬板？
- [ ] 能否用抗跌票修复替代直接撬跌停，把风险降一级？
- [ ] 交易原本是隔日套利还是趋势参与？退出纪律是否在买入前确定？
- [ ] 高位第二次冲高是充分换手的新周期，还是筹码交换不足的双头？

### 本课与后续学习的接口

- 前置输入：龙头辨识、板块联动、情绪周期、首板与一进二的基本理解。
- 向后输出：节点候选池、批量反馈确认、反核赔率评估和抗跌修复观察，可继续接入题材选择、筹码筛选、仓位与卖点系统。
- 尚未解决：节点池内部怎样按筹码和竞价进一步排序；不同情绪阶段应使用多大仓位；批量晋级率达到什么程度才足以确认新周期。这些仍需结合后续课程与实盘复盘补全。
