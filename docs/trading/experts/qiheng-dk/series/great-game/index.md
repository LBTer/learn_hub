## 概念与教学关系记录

第一课把原有的原则和退出意识接到金融史，但没有重新教授UBW、矩、2B等旧工具。不能把本课的宏观解释直接写成这些工具的触发条件。

市场先生一词在同一课中发生明确改造：先解释格雷厄姆寓言，再用奇衡自己的定义讨论竞争和资本力量。保留这个转换，避免把两种说法视为同一个原典定义。

课程同时赞成资本集中带来的生产能力，又强调信用扩张需要实体支持；这两部分是互补的条件，不宜只截取其中一面。竞争侵蚀利润与资本追求垄断，则是不同市场结构下的讨论，不能把作者的连接当作完全竞争模型的必然结论。

第二课从开篇概括进入具体故事与三次选择题，答案均在后续解释中揭晓；郁金香段还有明显的叙述反转。这是两课之间可见的教学差异，尚不称为全系列稳定变化。

第二课继续强调利益、执行条件与取舍，也出现需要分别保留的张力：赞成监督，同时批评精英替社会决策；用囤珠类比货币调节，却没有证明私人获利等于公共利益。后一课没有取消前一课的监督问题。
