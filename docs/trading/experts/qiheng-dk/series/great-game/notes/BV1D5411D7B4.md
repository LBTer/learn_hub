## 1. 高买低卖可能服务于更长的目标，但不能拿它解释所有盈利

**课堂问题（13:07—19:00）**：提诺的厂址离产地远，采购价又高，为什么还要低价出售？若只按一次交易的毛利理解，很容易觉得这种经营没有道理。

奇衡给出的链条是：外部融资支撑亏损，优先抢走货源，让竞争者缺料或滞销；等对手退出，再取得更强的定价权。农民在前一阶段可能得到好价格，却在买家减少后失去议价空间。于是，眼前受益和长期受益并不是一回事。

作者把它类比到中短线交易和量化策略：一段很好赚的钱，也许依附于更大参与者的阶段性行为。这个例子帮助提出**盈利的环境条件是什么**，却没有证明所有中短线利润都来自某个庄家主动让利，也没有给某个量化策略完成失效归因。

**整理者延展**：复盘时可以写下三件事——自己做了什么、当时哪些环境持续成立、什么变化会让这套做法失效。如果只能解释第一件事，就还没有解释可重复性。这里不需要先假设幕后有一个操纵者。

## 2. 仓单的价值，取决于谁能真正控制实物

**课堂问题（19:00—25:38）**：银行为什么愿意把钱交给提诺？仅有一个声称自己库存很多的商人，并不足以解释融资。

中间需要美国运通的仓储机构。它核验实物、签发仓单，借款人把凭证交给贷款人，贷款人依靠认证者的信誉放款。这样，银行不必亲自掌握每一罐油，却把部分核验工作交给了别人。

课堂的三个失效点很具体：场地仍在客户处、人员的实际依附没有独立、异常样本又交回被检查人的公司检验。油水与管道是作假的手段，**独立控制和异常处理缺位**才让手段反复奏效。

| 环节 | 正常情况下要确认什么 | 本课暴露的问题 |
| --- | --- | --- |
| 实物 | 数量、质量、位置及是否可交付 | 看见液面不代表全罐都是油 |
| 凭证 | 谁签发、承诺什么、是否真实有效 | 品牌被用作可信度，凭证可能与实物脱节 |
| 控制 | 谁能移动货物、谁保管、谁可处分 | 纸面职责改变不代表实际控制改变 |
| 复核 | 异常交给谁处理，能否独立取样 | 样品回到被检查方，未形成独立纠偏 |
| 融资 | 估值、折扣、可处置性与偿付路径 | 融资建立在错误数量或受影响价格之上 |

**整理者理解**：这一结构也适合阅读应收账款、存货和其他融资案例，但要重新确认各自的法律文件和流程。课堂把未来收入称为担保，表达的是经济偿付支持；不能据此把所有信用贷款都说成设有法律上的抵押或质押。

## 3. 最容易误读的两个分母：资本配置与公司所有权

**课堂问题（29:38—34:55）**：40%和5%为何同时成立？它们描述的不是同一个总体。

- 40%：这项投资占投资者一侧合伙资本的比例。
- 约5%：投资者买下了标的公司多大一部分权益。
- 5%—10%：另一份信里，对某一类通常较大单只持仓的资本配置描述。

奇衡把第三个数字与第一个对照，提出方法是否改变的疑问。这一步值得保留，因为同一个人不同年份的行为，需要相互比较；但原信的“通常”、证券类别及政策变动，必须一起阅读。

**外部核验**：1994年信确认首战约40%资本、超过5%权益。5%—10%段落来自回顾1961年表现的信，讨论Generals；1965年后来明确加入有条件的40%集中规则。后来的规则不能证明早先已经公布同一条款，也不能用早年的常见配置证明后来的交易一定有隐藏保证。参见[课程稿原信核验](../transcripts/BV1D5411D7B4#事实核验与边界)。

本课课件的115%收益、买卖年份和价格区间缺少完整成交明细，不把这些数拼成一个貌似精确的复算结果。2021年的持股市值也属于后来阶段。

## 4. 对调研的正确追问，是它能排除哪种风险

**课堂问题（28:22—32:46）**：奥马哈的顾客仍然用卡，能否推出一家全国公司的业务没有受损？

奇衡用地铁里找亿万富翁的类比指出选择样本的影响，又保留税单、水电数据交叉检查的价值。因此，本课并非简单主张不要调研，而是提醒研究动作与研究结论之间需要一座桥。

**整理者延展**：可以把调查结果分成三个层次。第一，实际看到了哪些地方的哪些行为；第二，在什么依据下推广到其他地区或客户；第三，这些行为对赔付、流动性、融资和资本缺口又意味着什么。客户仍在使用服务，能够提供业务延续的迹象，但并不自动排除所有财务风险。

样本不足以支持原结论，也不等于相反结论已被证明。课堂展示的流行故事不完整，并不能证明巴菲特只有这一小部分资料；同样，想象他掌握更多资料，也不能替代证据。

## 5. 把关系图拆成多种关系，才能知道哪里还缺证据

**课堂问题（34:55—45:33）**：为什么巴菲特敢集中投资少数企业？作者用共同创办人、家族邮购、金融与政治职位、合资、邻居和高尔夫谈话给出解释。

这些材料的证明力并不相同。成立年份与法律沿革可以查公司史；一次谈话可查当事人回顾；业务相关却不必然意味着具体两家企业合作；即便确实认识某人，也不能直接推出风险已经被排除。

| 已有材料 | 可以支持的范围 | 仍缺什么 |
| --- | --- | --- |
| 公司史中的共同创办人 | 企业之间有早期历史联系 | 后来股权、控制、责任是否延续 |
| 邮购需要运输的类比 | 值得查具体供应商关系 | 合同、账簿、通信及往来年代 |
| 高尔夫谈话的本人回顾 | 交流改变了对公司卡业务的判断 | 不能据此推定秘密信息或利益输送 |
| 股价后来恢复 | 结果符合当次判断 | 不能倒证当时没有失败风险 |

**外部核验的重点**：美国运通1850年成立，Wells Fargo于1852年另设，银行与快运1905年分离；它们不能被画成跨一百多年不变的简单分拆线。1997年巴菲特信确有1994年与Frank Olson交流后改为买入的回顾，这比纯粹类比有更直接的材料支持。来源与限定集中见[公司史及谈话核验](../transcripts/BV1D5411D7B4#事实核验与边界)。

作者自己的限定也重要：43:41以后明确不提倡观众照搬约高管打球，要求先理解别人方法的使用前提。

## 6. “投资操作”的单位，可以是一组相互配合的头寸

**课堂落点（46:37—47:54）**：原书页强调，证券不能脱离价格和组合被永久贴上投资或投机标签。组合中的相互关系可能改变风险，套利与对冲还涉及同时买入、卖出及整体安全性。

奇衡据此提炼价格、分散、适当套利对冲三点，接着用《乘风破浪》里多位艺人组成节目解释分散：事先不知道谁会走红，多人组合能覆盖不同可能。

**整理者理解**：娱乐组合只是直觉类比。证券组合还需要考虑投入比例、共同风险、亏损对象和成本；有人表现好，并不保证其收益足够覆盖其余部分。原书对某些操作的讨论，也不能变成所有持仓都必须配一条空头的统一规则。

## 整理者感悟：把怀疑变成可查的问题

**从近期顺利到环境解释（16:31）**：直觉上容易把连续盈利归给自己找到了方法。本课提供的改进，是把支撑盈利的参与者行为和环境也记入复盘。可做的练习是列出三个失效条件，并寻找能观察到的变化；不必为缺少证据的幕后故事填空。

**从资料很多到资料有效（28:22）**：三十厘米的资料会制造努力充分的印象，但材料厚度不直接回答样本偏差。可以为每一份材料注明来源、覆盖范围、它支持哪项结论及是否独立；多份材料若来自同一个口径，不能简单算作多次独立验证。

**从发现矛盾到查原文（32:46）**：40%与5%—10%的对比确实醒目，容易使人马上接受公开故事虚假的解释。更稳妥的下一步是找类别、日期、分母和例外，保留作者提出的问题，同时避免过早选定答案。

**从关系网到证据链（38:13）**：业务相互需要使联系显得很合理，但合理性只是调查起点。可给关系图每条线写上关系类型和证据出处；没有合同、通信或当事人材料的一条线，就继续保留为待查，而不因为整张图看起来完整就当成证明。

## 自拟练习：四个容易混淆的判断

以下均由整理者设计，不是作者原题；算术条件是假设，不能作为本案真实交易记录。

### 练习一：两个比例的分母

假设一个组织资本为3250万美元，花1300万美元买到某公司的5%股份。投入占自身资本多少？若简单按同价同比例推算，这笔价格对应标的整体权益价值多少？这是否就是公司的内在价值？

<details>
<summary>参考答案</summary>

1300÷3250＝40%；1300÷5%＝26000万美元，即2.6亿美元。后者只是题设下按成交价格外推的权益规模，不是独立估值，也未包括交易费用和不同股份权利。真实首战原信是超过5%，不能直接套题中的恰好5%。

</details>

### 练习二：库存、仓单与赔付

资料甲说实物600万美元、仓单1亿美元；资料乙说相关贷款责任约1.44亿美元；资料丙说母公司后来出资6000万美元。能否把三份资料写成“公司有1.44亿美元存货，最后亏6000万美元”？

<details>
<summary>参考答案</summary>

不能。先分别标注主体、日期、数值含义，再查是否含伪造凭证、不同债权人或其他安排。出资也不自动等于税后最终经济损失；需要更多会计资料。练习目的在于识别口径，不能把不同数字强行平均或任选一个。

</details>

### 练习三：十家餐馆的调查

某地十家餐馆仍接受一种支付工具，观察到的顾客使用量稳定。请写一个证据直接支持的结论，再写两个目前不能支持的结论。

<details>
<summary>参考答案</summary>

直接支持：在选取的这些地点和观察时段，接受及使用情况未见明显变化。尚不支持：全国客户都未减少使用；公司必定能承担全部法律赔付并避免融资压力。要推广，需要说明抽样方式、地区与客户覆盖、观察时长和其他资料的交叉结果。

</details>

### 练习四：给关系图的箭头写名字

已知甲乙企业有共同创办人；几十年后各自经历多次重组；投资者认识乙的客户。能否画“甲控制乙，因此投资者知道乙不会倒闭”的箭头？还缺哪些材料？

<details>
<summary>参考答案</summary>

不能。共同创办、目前控制、客户关系、投资者的信息来源以及不倒闭保证是不同判断。需要逐段查当时的股权和法人沿革、往来证据、沟通内容、财务承受能力及任何真实承诺。找不到时保留未知，不拿后来盈利补上。

</details>

## 本课核验后的复习卡

| 可以带走的判断能力 | 不能一起带走的过度结论 |
| --- | --- |
| 检查融资链中的实物、凭证、控制和复核 | 大品牌签字就保证库存真实，或检查失效就证明全员共谋 |
| 比较比例时先找分母、类别和时间 | 旧信中的通常配置是永久上限，超过就证明公开理由虚假 |
| 问调研样本覆盖谁、排除了什么 | 去过现场就足够，或有样本局限就说明调研没有价值 |
| 研究信息来源和方法使用前提 | 认识高管等于掌握内幕或拥有保底 |
| 看整个投资操作的价格与组合关系 | 不必研究价值，或组合里有一个赢家就必定赚钱 |
