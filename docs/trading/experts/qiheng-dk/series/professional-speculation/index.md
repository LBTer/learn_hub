# 《专业投机原理》系列学习地图

本系列接续《股票作手操盘术》，按奇衡的授课内容学习《专业投机原理》（课内俗称“砖头”）。第一课先讨论美元与市场环境，第二课继续讨论机会、参与周期和认错条件，第三课以鳄鱼法则讨论判断失效后的退出，第四课转入对道氏理论的批判、指数确认与成交量，第五课将资金角色与趋势观察联系起来，第六课用 2B 结构讨论避险、认错与重新参与，第七课再把结构判断接到计划、执行和记录，第八课补交易环境、持续成交与产品选择；后续结构随实读更新。

**教学方式记录：** 本系列开篇用了较多人物与政策故事，先搭背景；对照上一系列，是内容范围的变化，暂不能据一课判断作者理论已修正或已经形成统一体系。尊重经典同时提出异议的阅读方式仍然可见。第二课采用概念分类、个人经验与开放式寓言，属于教学表达的变化；不据此宣布第一课宏观判断已获证明或被撤回。第三课改用喜剧、漫画、历史对白和双案例对照，深化认错条件；案例叙事的感染力与事实证明力分开，不按新课出现就认定理论进步。第四课采用逐条反驳后保留工具的方式，并给出历史指数条件；属于观察条件补充，不等于其强因果判断获得证明。第五课以遮挡后续行情、理想与不规则示意图、同图三种角色对照深化看图前提；属于条件补充，未宣布完成趋势线技术体系。第六课以跨时期案例和未来分支示意讲可修正的应对；重现上一系列浪形并新增失败经历，属于执行条件深化，不把初始 2B 与所有扩展结构合并。第七课从图形追问转到概率、数列前提及逐条守则辨析，加入模型展示和人工维护细节；属于条件补充与教学方式变化，未据展示收益宣布体系已经验证。第八课以狩猎和农耕类比引出长期量能及成交额榜单，明确补讲守则 12；属于交易前提深化，未把类比、行业故事或排行榜视为实证策略。
