## 方法定位

Rhino将盈利预期、资本开支及融资条件用于解释指数风险。本卡仅保留研究问题，不复制课程全部参数。

| 记录项 | 必须保存的证据 | 反证问题 |
| --- | --- | --- |
| 盈利修订 | 公司指引、共识日期、EPS口径 | 是普遍下降还是少数公司变化？ |
| 资本开支 | 公司范围、现金/租赁口径、财年 | 支出降低是否来自效率提升而非需求下降？ |
| 收入兑现 | 订单转收入、利润率、经营现金流 | 收入增长能否覆盖持续投入？ |
| 融资压力 | 债务期限、利差、租赁及担保 | 利率上升是否真正传导到该公司？ |
| 价格背景 | 同一时点价格与估值版本 | 弱预期是否已经反映？ |

## 适用边界

这是季度研究清单，不是日内择时。指标相关性变化不直接证明因果。先定义触发、观察期限和反例，再保存结果；没有原始数据时标注“视频引用”，不统计命中率。

## 第305期补充：研究记录的可比性

以下是整理者设计的检查清单，并非作者公开了完整数据库算法：

- 每次记录来源、获取日期、目标财期、滚动或固定期限、GAAP或调整口径、预测或实际、样本数量。
- 同财期修正、同比增长、超预期幅度、覆盖样本变化分开存储；滚动窗口自然推进不全部计为上修。
- 指数与七巨头/其余公司分开看，利润总额、每股值与利润率不混用。
- 保留异常值与排除理由；另看GAAP调节表和现金流。多个展示网站可能共享数据源，不自动视为独立验证。
- 当前没有固定交易阈值或回测结果，不能由“前瞻线拐头”直接触发普适买卖规则。
