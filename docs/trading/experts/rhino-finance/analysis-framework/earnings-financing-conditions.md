# 盈利—融资条件观察卡

状态：跨期学习候选，未回测，不是稳定策略。首次来源：[第304期笔记](../member-notes/2026-10-04-V11vKrhYRpI.md)，原视频约07:41、19:45、22:19、29:24。

## 方法定位

Rhino将盈利预期、资本开支及融资条件用于解释指数风险。本卡仅保留研究问题，不复制课程全部参数。

| 记录项 | 必须保存的证据 | 反证问题 |
| --- | --- | --- |
| 盈利修订 | 公司指引、共识日期、EPS口径 | 是普遍下降还是少数公司变化？ |
| 资本开支 | 公司范围、现金/租赁口径、财年 | 支出降低是否来自效率提升而非需求下降？ |
| 收入兑现 | 订单转收入、利润率、经营现金流 | 收入增长能否覆盖持续投入？ |
| 融资压力 | 债务期限、利差、租赁及担保 | 利率上升是否真正传导到该公司？ |
| 价格背景 | 同一时点价格与估值版本 | 弱预期是否已经反映？ |

## 适用边界

这是季度研究清单，不是日内择时。指标相关性变化不直接证明因果。先定义触发、观察期限和反例，再保存结果；没有原始数据时标注“视频引用”，不统计命中率。

## 第305期补充：研究记录的可比性

以下是整理者设计的检查清单，并非作者公开了完整数据库算法：

- 每次记录来源、获取日期、目标财期、滚动或固定期限、GAAP或调整口径、预测或实际、样本数量。
- 同财期修正、同比增长、超预期幅度、覆盖样本变化分开存储；滚动窗口自然推进不全部计为上修。
- 指数与七巨头/其余公司分开看，利润总额、每股值与利润率不混用。
- 保留异常值与排除理由；另看GAAP调节表和现金流。多个展示网站可能共享数据源，不自动视为独立验证。
- 当前没有固定交易阈值或回测结果，不能由“前瞻线拐头”直接触发普适买卖规则。

## 第306期补充：从预测到估值的版本约束

来源：[2026-10-18笔记](../member-notes/2026-10-18-A4p5t_F4mQs.md)，原片02:13、18:05、20:51、24:17。状态仍为跨期候选，不因增加一期样本就视为稳定体系。

- 预测日期与目标财年分别保存；下一年同比下降不等于下一年预测被下修。
- 财年截止日写完整；表格年份、自然年和公司正式财年有冲突时先核对。
- EPS和估值倍数分别做敏感性分析，不把周期高点盈利计算出的低PE当无条件安全。
- 估值模型、技术结构、催化剂及个人仓位约束分栏，避免以其中一项代替全部判断。
- 自选55家公司不是市场代表样本，不能用上修家数直接推断指数整体。

## 10月23日补充：融资到收入兑现的证据链

来源：[公开复盘](../market-reviews/2026-10-23.md)，原片05:14—20:06及21:09。以下是整理者据本期设计的验证清单，不是已回测的择时规则。

- 将融资依赖较强的运营商、多业务现金流公司、硬件供应商分开记录；不把共同AI标签当成同等偿债能力。
- 逐项核查融资规模/成本/期限、项目执行、客户付款、供应商收入及利润。某一环承压不能直接证明后续全已恶化。
- 股权分配、融资增发、现金到账、投票权、每股收益和投资回报分别建模；未知发行规模只能做情景，不推出确定跌幅。
- 同时保存反证：再融资顺利、回款改善、采购效率变化等是否缓解压力。单日跌价不作为整条因果链被验证。
- 信用衍生品推算需要模型与回收率；没有底稿的违约概率不进入命中率统计。本期未给可检验期限，不新增已兑现预测。

## 10月24日补充：建设状态不能混同

来源：[公开复盘](../market-reviews/2026-10-24.md)，原片06:35—14:05。融资能力之外，增加审批、电力/设备、在建和投产状态；“宣布但未开工”不自动计为延期或取消。跨年度管线图须保留样本、统计日期和预计运营年份，不能把整根柱子当作当年实际投产。已有算力可能受益于延期只是条件情景，仍要核查利用率、租约、成本与负债，不据此建立无条件多头规则。

## 10月27日补充：资金与估值都需要版本

来源：[第307期](../member-notes/2026-10-25-e-_qeTZQnkU.md)02:21、07:54、15:10与[公开复盘](../market-reviews/2026-10-27.md)02:22—09:06、17:19。仍为研究候选，未回测。

- 每项融资分别记录计划、签署承诺、交割条件、到账/设备交付和取消条款，不因公告发布就全部记为完成。
- 股权、债务、供应商融资与现金流分栏；股权筹资不自动证明债务渠道关闭，合同金额也不是利润。
- 历史估值版本不可由后来公告覆盖；新股发行或资本开支变化，应重新检验每股口径。
- 会员估值表中的财年标签与正式财年对齐，业务模式决定研究指标；REIT、指数数据服务和制造业不可套同一收入/盈利逻辑。
- 低估、技术触发、个人计划、真实成交分别留痕；不能以“有意买入”反推已经持仓。

## 10月28日补充：证据指标应与问题匹配

来源：[公开复盘](../market-reviews/2026-10-28.md)，原片06:47、13:51、16:40。以下是整理者对数据使用的修正，不是新增择时规则。

- 因子敞口、净杠杆、总杠杆、资金流和空头回补不是同一指标。动量因子曲线不能单独解释新增买盘或证明长期资金退场。
- 广度统计保留最大回撤/累计收益定义、起始日、样本和截面日期；表内数字与图题冲突时标注冲突，不选择更符合故事的一个。
- 期权隐含区间与技术关键位可以并列比较，但没有原始合约和模型时不宣称准确概率、确定方向或最大损失。

## 10月29日补充：兑现与日历口径

来源：[公开复盘](../market-reviews/2026-10-29.md)，原片08:22、21:06、23:15、27:11。仍为研究清单，不是经过回测的交易模型。

- 财年、自然年与设备交付期分别记录；交付延迟不自动归类为需求取消。
- 收入增长、预期差、营业利润和现金流分栏，现金资本开支不与含租赁投入直接混加。
- RPO存量变化需用新签、确认收入、取消及汇率解释；仅存量平稳不能确认变现效率提高。
- 公司经营现金充足与是否主动融资分开判断；融资可能改变资本结构，并非必然代表资金断裂。
- 对价格的行动保留时间条件：快速到达与随盈利增长逐步到达同一价格，未必对应相同估值或减仓意愿。

## 10月30日补充：窗口、利差与融资阶段

来源：[公开复盘](../market-reviews/2026-10-30.md)，原片15:58、22:44、25:45。以下为整理者的数据校验约束，不是新交易信号。

- 先统一单季、年初至今、滚动12个月窗口，再比较自由现金流。不能沿用AMZN页面将TTM误标单季的数字做跨公司排名。
- 净借款流量、债务余额、认购需求、募集总额与净到账分别记录，定价不是交割。
- 利差、基准利率和票息分开，比较时匹配期限与固定/浮动结构；信用利差缩小不能证明总成本下降。
- 业务与市场预期差先核实样本和口径；营业利润金额不写成利润率，估值未更新就不代作者补出新版本。
