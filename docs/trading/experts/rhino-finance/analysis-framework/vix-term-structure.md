## 方法定位

Rhino 将 VIX 与 VIX3M 的相对水平用于辅助判断市场压力，并与价格结构、仓位状况共同考虑。它不是独立的方向预测指标。本卡是自主研究提纲，不复制课程整套操作参数。

## 最小观察记录

| 字段 | 要求 |
| --- | --- |
| 交易日与取值时点 | 同一时点，不混用盘中与收盘 |
| VIX、VIX3M | 保存原始值，并附来源 |

| 研究结论 | 当前观察、可能的反例、下一次复核条件 |

## 反证优先

- R 回落是否只是分母上升，而非近端压力下降？
- 一次穿越是否很快反复，造成高额调整成本？
- 价格是否仍在走弱，否定了过早的“风险解除”解释？
- 相同信号对无杠杆分散组合与集中高 beta 组合，是否根本不应采用相同行动？

## 验证路线

先积累观察，再制定不含未来信息的事件定义；分开统计首次进入倒挂与退出倒挂。报告样本量、收益分布、最大不利变动、基准比较和成本。没有这些证据，不将课程的历史统计升级为策略保证。
