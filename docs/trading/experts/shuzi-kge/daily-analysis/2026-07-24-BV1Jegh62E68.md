## 知识点

### 1. “横盘很久”不等于完成调整

作者将结构质量拆成空间、时间和内部换手：空间上的回调不足、时间上的拉长不够、震荡主要是单段式运行时，横盘可能只是拖延并消耗多头，而非健康蓄力。适用条件是能看见内部换手和承接，失效条件是价格形成完整突破结构并持续推进。

### 2. 突破后的收回仍需行为确认

趋势线跌破后重新收回，或一根 K 线看起来漂亮，都不足以单独证明反转。分析者延展来看，应继续观察后续是否站稳、是否有连续性，以及能否完成作者提出的强反弹结构；瞬时收回和单根阳线都属于待验证信号。

### 3. 远期波浪框架不能替代短线风控

作者同时讨论熊市末期、未来大 C 浪、超级循环五浪和百万美元目标。可迁移的纪律是：远期方向判断必须与当前周期、仓位和失效条件分层；即使长期看好，也不意味着短线可以忽略回撤或使用无法承受的杠杆。

### 4. 单一衍生指标不能直接变成开仓按钮

资金费率在不同市场阶段可能处于不同常态，也可能被交易行为影响；清算地图同样只是信息之一。适用方法是把指标放入价格结构、趋势、成交和历史样本中验证，失效条件是只凭一个数值直接开仓。

### 5. 相对强弱可作为节奏先行观察

作者把 ETH/BTC 向下跌破趋势线当作 ETH 相对 BTC 转弱的先行信号。分析者延展来看，相对强弱更适合用于比较参与顺序和回撤弹性，不能单独推出长期方向结论；仍需结合 BTC 主结构和 ETH 自身价格确认。
