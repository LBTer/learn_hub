## 知识点

### 1. 突破确认应跨过第一次完整回调

作者给“站稳”设置了时间和结构条件：相同级别的突破发生后，首次下跌线段走完仍不跌回，才有较强的确认意义。分析者延展：观察回调完成、支撑接受和再次推动，比单看刺破压力后的即时位置更能排除短时假突破。

### 2. 回撤比例只是地图，收回动作才提供证据

0.382、0.5 和 0.618 是作者定位潜在调整区的工具。BTC 约 76,000 的剧本尤其强调假跌破后收回；若收不回，需继续考虑更深回撤。分析者延展：价格区间、结构完成和风险失效应写成三项条件，避免将理论比例当作自动进场指令。

### 3. 短空与长期现货可以同时存在

作者短线持有 BTC、ETH、SOL 空单，同时长期持有 ETH 与 DOGE 现货。两者分别对应回调和周期上涨预期。要理解其行动，需记录时间级别、仓位大小和退出条件，不能只抽取某一方向的口号。

### 4. 高倍数目标要同时记录成本、仓位和兑现条件

DOGE 的“30 倍”建立在作者自述约 0.07 美元成本及 2 美元附近的远期目标上，不是当前收益。他又明确表示山寨币配置很小。分析者延展：评估类似观点时，至少要核对可验证的入场成本、资金占比、持有周期、逐步卖出条件与结构失效条件。
