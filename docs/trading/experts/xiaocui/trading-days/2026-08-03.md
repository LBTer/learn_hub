## 本期知识点

- **PE 与 EPS：** 利率上升可以压缩 PE，但盈利高速增长可能抵消估值下修；应把利率、盈利增速和前瞻指引放在同一框架中。
- **左侧与右侧交易：** 左侧提前押注政策或周期转向，价格可能更有利但不确定性更高；右侧等确认，代价是可能错过低价。
- **杠杆 ETF 的路径依赖：** 每日复位、融资、保证金和强平会放大波动；监管改变保证金或产品规则时，存量投资者与新投资者面临的风险不同。
- **AI 资本开支链条：** 数据中心、芯片、云平台、模型 API 和企业工作流需要分别观察；资本开支增加不等于必然泡沫，也不等于必然盈利。
- **模型价格不等于商业模式：** 低 API 价格可能来自架构效率、规模效应、补贴或短期亏损；应等待利用率、毛利率、现金流和客户留存验证。
- **主动 ETF 的透明度与费用：** 主动管理费、区域暴露、集中持仓和基金经理权限会影响结果；不能只比较买入价。
- **新手纪律：** 小翠本期反复强调不要加杠杆、不要追高、不要把 AI 当真理、不要把主播当实时交易指令；任何价格区间都要结合期限、仓位上限、家庭现金流和回撤承受力。
